# Security policy

## Supported versions

Security fixes go to the latest commit on `master`.

## Reporting a vulnerability

Email jonas.hagmar@protonmail.com. Say which path is affected and how to reproduce it.

You will receive an acknowledgement within 7 days. A fix, or a clear status if a fix will take longer, follows within 30 days. Keep an unfixed vulnerability off the public issue tracker. A public issue or pull request is for a fix that is already disclosed.
